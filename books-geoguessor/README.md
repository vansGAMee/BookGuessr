# BookGuessr 📚

**BookGuessr** — браузерная игра в стиле GeoGuessr по классическим произведениям русской литературы.

Игроку дается отрывок из книги размером в одну страницу, а его задача — определить место этой страницы на шкале произведения от 0% до 100%.

---

## 🚀 Особенности

- 📚 **Реальные тексты русской классики** (общественное достояние: Достоевский, Толстой, Тургенев, Гоголь, Лермонтов, Пушкин, Чехов).
- 🎮 **2 режима игры**:
  - *Случайная классика*: 5 раундов по случайным произведениям.
  - *Выбрать книгу*: все 5 раундов по выбранному произведению.
- 🎯 **Нелинейная система очков**: до 5 000 за раунд и 25 000 за матч.
- 📲 **Результат Wordle/GeoGuessr**: быстрое копирование текстового отчёта с результатами 5 раундов в буфер обмена или через Web Share API.
- 🔒 **Полностью static**: 0 внешних API во время игры, 0 серверов, 0 ключей, идеальная совместимость с **Vercel**.

## 🛠 Запуск и разработка

```bash
# 1. Установка зависимостей
npm install

# 2. Локальный запуск
npm run dev

# 3. Production Сборка
npm run build

# 4. Просмотр Production сборки
npm run preview
```

---

## ⚡️ Деплой на Vercel

Проект готов к деплою на **Vercel** без сервера и переменных окружения:

1. Импортируйте Git-репозиторий в Vercel dashboard.
2. Vercel автоматически определит **Vite**.
3. Нажмите **Deploy**.

Production output создает полностью статическую папку `dist/`.
